# Metal Sentinel

> Real-time and historical precious and base metal prices, plus crypto, forex and mining stock quotes, through a single fast REST API.

Metal Sentinel is a market data API sold through RapidAPI. It offers a free plan with 7500 requests per month and no credit card required, and every plan gets the same data: live spot quotes for ten metals refreshed every 15 seconds, historical daily prices, and mining stock quotes. Pricing and plan limits: https://metal-sentinel.com/pricing

## Features

- Free plan with 7500 requests per month, 60 requests per minute
- Ten spot-traded metals: gold (AU), silver (AG), platinum (PT), palladium (PD), rhodium (RH), copper (CU), nickel (NI), aluminum (AL), lead (PB), zinc (ZN)
- Quotes in 180+ fiat currencies and 90+ crypto tokens
- Gold karat prices (24k, 18k, 14k, 9k) and silver fineness prices (925 and more)
- Historical daily price data with configurable date ranges
- Market status (open/close) with next transition time
- Mining and commodity equities data
- Free embeddable price widgets, no API key required

## Authentication

All endpoints are REST (GET) on `https://metal-sentinel.p.rapidapi.com` and require two headers issued by RapidAPI: `x-rapidapi-key` (your key) and `x-rapidapi-host: metal-sentinel.p.rapidapi.com`.

Example:

    curl "https://metal-sentinel.p.rapidapi.com/api/metal-quote?symbol=AU&currency=USD" \
      -H "x-rapidapi-host: metal-sentinel.p.rapidapi.com" \
      -H "x-rapidapi-key: your_key"

## API Endpoints

Full reference with parameters and sample responses: [API Endpoints](https://metal-sentinel.com/endpoints)
Machine-readable description: [OpenAPI 3.1 spec](https://metal-sentinel.com/openapi.json). API catalog (RFC 9727): https://metal-sentinel.com/.well-known/api-catalog

- `/api/metal-quote?symbol=AU&currency=USD` — Current spot price for one metal in one currency
- `/api/gold-price` — Gold spot price with calculated karat prices
- `/api/silver-price` — Silver spot price with calculated fineness prices
- `/api/metal-history` — Historical daily prices with configurable date range and limit
- `/api/historical-points` — Point-in-time snapshots at 30d, 60d, 1y and 5y intervals
- `/api/crypto-quote` — Live cryptocurrency quotes with 24h comparison
- `/api/forex-quote` — Foreign exchange rates with USD conversion
- `/api/get-stock` — Live mining and commodity equities data
- `/api/market-status` — Market open/close status and next transition time
- `/api/allowed-metals` — Supported metal symbols
- `/api/allowed-currencies` — Supported fiat currency codes
- `/api/allowed-cryptos` — Supported cryptocurrency symbols

## Embeddable Widgets

Free, embeddable metal price widgets that work on any website. No signup, no API key, no script dependencies. Each widget is a single `<iframe>` snippet.

- Widget URL: `https://metal-sentinel.com/widget/{symbol}?currency={code}&theme={theme}`
- Supported symbols: AU, AG, PT, PD, RH, CU, NI, AL, PB, ZN
- Supported currencies: 180+ fiat codes (USD, EUR, GBP, JPY and more)
- Themes: `light`, `dark`, `vibe`, `artistic`, `industrial`, `space`
- [Widget configurator and live demo](https://metal-sentinel.com/widgets)
